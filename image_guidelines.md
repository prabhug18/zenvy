# Platform Image Requirements

Please provide the images in the exact dimensions listed below to ensure they display perfectly on the platform.

### Core Assets
* **Main Header Logo:** `100 x 35` px *(Used in the top navigation)*
* **Dark Mode Logo:** `100 x 35` px *(Used when dark mode is enabled)*
* **Footer Logo:** `160 x 45` px *(Used at the bottom of the site)*
* **Icon Logo:** `40 x 40` px
* **Favicon:** `16 x 16` px *(The small icon on the browser tab)*

### Course & Media
* **Course Thumbnail Image:** `300 x 300` px
* **Featured Videos Thumbnail:** `300 x 300` px *(Or `1280 x 720` for a standard wide video look)*

### Profiles
* **Instructor Profile Image:** `200 x 200` px
* **Student Profile Image:** `200 x 200` px
* **Testimonial Profile Image:** `120 x 120` px

### Banners
* **About Us Banner Image:** `1920 x 1080` px *(Standard high-resolution wide format recommended)*
